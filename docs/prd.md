产品需求文档 (PRD): 乘黄字游 (Horned Fox Words)

1. 产品概述
⚬ 应用名称：乘黄字游 (Horned Fox Words)
⚬ 目标平台：iOS 17.0+ (SwiftUI，通用 iPhone/iPad)
⚬ 应用分类：教育 / 图书 (Education / Books)
⚬ 商业模式：付费下载（一次性买断，100% 单机纯净模式，无 App 内购，无需网络）
⚬ 核心定位：一款面向 K12/K15 学生及国风文化爱好者的沉浸式古典文学拼字解谜 App。玩家骑乘《山海经》神奇坐骑“乘黄”，穿梭于两千年的中国古代文学，通过拼字解谜唤醒典故与诗词，并收集 100+ 历史人物勋章。
2. 产品目标与成功指标
⚬ 主要目标：提供无广告、零干扰的纯粹单机国学解谜体验，将枯燥的古典文学背诵转化为富有吸引力的拼字游戏。
⚬ 目标受众：
⚬ K12/K15 学生（小学至高中），寻找趣味语文拓展与提分工具。
⚬ 家长群体，青睐无广告、安全、高质感的 iOS 教育类应用。
⚬ 国学及古风文化爱好者。
⚬ 成功指标：
⚬ 7 日留存率 > 40%
⚬ 平均关卡完成率 > 80%
⚬ App Store 崩溃率 < 0.1%
3. 核心功能与需求
3.1 拼字闯关系统
采用字块选择矩阵机制，提供三条平行推进的文化主线：
文化主线 选材来源 核心玩法与奖励
史汉典故 《史记》《汉书》《战国策》 拼接 4 字成语，解锁 100 字历史故事与人物卡片。
诗经风雅 《诗经》（风 / 雅 / 颂） 还原名句字块，解锁生僻字注音与名句赏析。
唐诗宋词 《唐诗三百首》、宋词名篇 补全诗词名句，解锁出处背景与作者生平。
3.2 吉祥物“乘黄”伴学系统
⚬ 形象定位：脚踏祥云的神兽乘黄。
⚬ 形态进化：
 1. 幼年乘黄：初始默认形态。
 2. 墨香乘黄：累积 1,000 积分解锁。
 3. 凌云神黄：累积 5,000 积分解锁，具金角与卷轴圣物。
⚬ 交互反馈：主页展示励志名言、通关动画联动，并在卡关时提供灵感提示。
3.3 百杰勋章收集系统 (100+ 勋章)
⚬ 解锁机制：通关带有特定历史人物或时代 Tag 的关卡（如诸葛亮、秦始皇、李白）。
⚬ 勋章分类：
⚬ 帝王将相（秦始皇、刘邦、诸葛亮、韩信）
⚬ 先贤名臣（孔子、老子、司马迁、班固）
⚬ 诗词大家（李白、杜甫、苏轼、李清照）
⚬ 史籍名篇（诗经、史记、汉书）
⚬ 视觉呈现：古风朱砂/青铜印章样式，带有解锁进度指示（如 2/4）。
4. 用户旅程与界面结构
[启动 App] -> [主页仪表盘] -> [选择主题] -> [拼字关卡] -> [故事卡片 Modal] -> [解锁勋章]
                  |                                                                |
                  +--> [乘黄进化卡片]                                              +--> [勋章馆]
