# 文绉绉·甪端 (luDuan) — 产品需求文档 + 功能规格

## 1. 产品概述

- 应用名称：文绉绉·甪端 (luDuan) — 原名《甪端字游》
- 当前版本：v1.2.0 (Build 12)
- 目标平台：iOS 17.0+ (SwiftUI) / Android 8.0+ (Kotlin + Jetpack Compose)
- 应用分类：教育 / 图书
- 商业模式：付费下载（一次性买断，单机纯净，无内购，无需网络）
- 核心定位：面向学生及国风文化爱好者的沉浸式古典文学拼字解谜 App。骑乘神兽甪端，穿梭两千年中国古典文学，通过拼字解谜唤醒典故与诗词，收集百杰勋章。
- 数据持久化：以"词（短语）"为单位（learnedPhrases），Keychain/EncryptedSharedPreferences 存储，跨版本/卸载保留。

## 2. 数据架构

| 数据 | 存储 | 说明 |
|---|---|---|
| 勋章目录 | `badges.json`（166 枚扁平数组） | 代码仅 JSON 解码，增删改数据只动 JSON |
| 关卡种子 | 43 个 JSON 文件（shihan/lunyu/...） | 懒加载缓存，万关程序化生成 |
| 勋章图 | BadgeImages/ 目录 | 人物真实画像 / 学阶明代官服 / 典籍书面 / 修养水墨 |
| 用户进度 | learnedPhrases Set + unlockedBadges Set | 加密持久化 |
| 种类 | 人物62 / 学阶23 / 典籍41 / 修养40 = 共166枚 | |

### 3.3 闯关界面 (PuzzleGameView) — 核心

#### 顶栏

| 元素 | 交互 |
|---|---|
| ← 返回 | dismiss 回首页 |
| 标题 | 「分类名 · 第 X/Y 词」实时进度 |
| ⏮ 上一关 | 有上一关时显示 → 切关（重置引擎） |
| ⏭ 跳过关 | 强制完成当前关 → 切下一关 |
| ✨ 灵感 | 打开灵感面板（典故原文 + 渐进提示） |

#### 线索卡片

| 内容 |
|---|
| PaperCardView 金边卡片，「线索」标题 + level.annotation 释义文字 |

#### 答题槽 (已选字展示区)

| 元素 | 交互 |
|---|---|
| 每槽：圆角矩形 + 边框 | — |
| 已选字：拼音 + 汉字（朱砂红） | **点击已选槽 → 取消选字**（字块恢复可选，播 tap 音效） |
| 未选槽：灰色横线占位 | — |
| 答错 | **整体左右抖动 4 次**（shake 动画） |

#### 提示气泡（条件显示）

| 显示条件 | 内容 |
|---|---|
| engine.highlightedTileIndex != nil | 「甪端指引：已锁定 1/2 个正确字！」 |

#### 字块矩阵

| 元素 | 状态 | 交互 |
|---|---|---|
| 4列网格 16字块 | 默认白底灰边 | — |
| | 已选 → 朱砂红底+红边+红字 | disabled |
| | 高亮（提示）→ 金边 3px | — |
| Button | — | **点击 → 选入答题槽**（播 tap 音效 + 轻触震动） |

#### 底部操作栏

| 按钮 | 交互 |
|---|---|
| 🔄 重置 | 清空所有已选字 |
| 🎤 语音拼字 | 模拟器：弹输入框；真机：SFSpeechRecognizer，含 debounce 0.3s + 乱序容错 |
| ✅ 完成拼字 | → checkAnswer()：正确触发通关；错误→失败音效+抖动 |

#### 通关流程

```
通关 → completeLevel(记词+解锁勋章+保存)
     → count = learnedPhrases.size
     → 延迟 0.4s
     → count % 10 == 0 ? 弹里程碑(礼花+分享) : 弹故事卡
```

#### 灵感面板（渐进提示）

| 阶段 | 按钮文字 | 效果 |
|---|---|---|
| 0 | 提示 1 个正确字块 | 高亮 1 个目标字 |
| 1 | 提示 2 个正确字块 | 高亮 2 个目标字 |
| 2+ | 解锁全部正确字通关 | 自动填入全部正确字 |
