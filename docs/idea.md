# 《乘黄字游》App 项目策划与架构简案 (idea.md)

## 一、 项目概述

* **应用名称**：乘黄字游 (Cheng Huang Zi You)
* **应用口号**：骑乘神兽，穿越千年的字里行间。
* **目标受众**：K12/K15（中小学生）、国风文化爱好者、双语/大语文解谜玩家。
* **IP 与隐喻**：以《山海经》神奇坐骑“乘黄”（乘之寿二千岁）为吉祥物。玩家骑乘神兽乘黄穿梭于两千年的中国古代文学，通过拼字解谜唤醒历史典故与诗词。

---

## 二、 核心机制与特色

1. **三大文化主题关卡**
    * **史汉典故关**：解开《史记》《汉书》《战国策》成语，解锁历史故事与人物卡片。
    * **诗经风雅关**：拼合《诗经》（风/雅/颂）名句，展示生僻字注音与名句赏析。
    * **唐诗宋词关**：精选《唐诗三百首》与宋词名篇，主打选字还原与出处拓展。
2. **“神兽乘黄”游历进化系统**
    * **形态成长**：从“幼年小乘黄”随着通关积分积累，进化为带有祥云与金角的“万卷乘黄”。
    * **游历助手**：关卡中提供国风古韵提示，增强 K12/K15 用户的陪伴与沉浸感。
3. **百杰勋章图鉴 (100+ Badges)**
    * 完成特定人物/主题相关关卡（如诸葛亮、秦始皇、李白、苏轼），解锁专属古风印章勋章。
